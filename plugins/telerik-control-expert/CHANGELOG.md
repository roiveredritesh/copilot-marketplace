# Changelog - Telerik Control Expert Plugin

All notable changes to this plugin will be documented in this file.

## [2.0.0] - 2026-01-16

### Added
- Initial production release
- Telerik Troubleshooter agent for comprehensive diagnostics
- Telerik Migration Advisor agent with Blazor/React/Angular mapping
- Telerik Property Analyzer agent for configuration optimization
- Support for all major Telerik controls (RadGrid, RadComboBox, RadEditor, RadAjax, etc.)
- Deprecated property detection with alternatives
- Performance analysis with ViewState optimization
- AJAX configuration validation
- JavaScript and client-side diagnostics
- Migration effort estimation
- Control mapping to modern alternatives
- Best practice validation
- 3 commands for troubleshooting, migration, and analysis
- 2 shared skills for Telerik expertise and modernization

### Supported Controls
- RadGrid (data binding, paging, sorting, filtering, editing)
- RadComboBox (data binding, cascading, client-side operations)
- RadEditor (toolbar, content filtering, file upload)
- RadAjax (AJAX panels, loading icons, partial postbacks)
- RadWindow (modal windows, callbacks, navigation)
- RadScheduler (rendering, data binding)
- RadTreeView (navigation, data binding)
- RadMenu (navigation)
- RadDatePicker, RadTimePicker, RadDateTimePicker
- RadTextBox, RadNumericTextBox
- RadTabStrip, RadMultiPage
- RadSplitter, RadPane

### Migration Targets
- Blazor (Telerik Blazor, native components)
- React (KendoReact, AG-Grid, React-Select, etc.)
- Angular (Kendo Angular, Angular Material, AG-Grid)

### Analysis Capabilities
- Configuration validation
- Deprecated property detection
- Performance optimization
- Best practice validation
- Version compatibility checking
- ViewState analysis
- AJAX configuration review
- Client-side code validation

### Documentation
- Complete agent specifications following v2.0.0 template
- 6-phase processes for all agents
- Error handling scenarios
- Configuration options
- Comprehensive examples
